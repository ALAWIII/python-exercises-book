# أنواع البيانات والتحويل بينها

## ماذا سنتقن؟

بنهاية هذا الفصل ستتمكن من:

1. التمييز بين أنواع البيانات الأساسية: الأعداد الصحيحة (`int`)، العشرية (`float`)، النصوص (`str`)، والمنطقية (`bool`).
2. استخدام الدالة `type()` لمعرفة نوع أي قيمة أو متغير.
3. تحويل البيانات من نوع إلى آخر باستخدام `int()` و `float()` و `str()`.
4. فهم سبب حدوث أخطاء عند محاولة جمع النصوص مع الأعداد وكيفية حلها.

📖 يقابل هذا الفصل: **الفصل 6 «أنواع البيانات والتحويل بينها»** من كتاب «البرمجة بلغة بايثون».

## مراجعة سريعة

هذا الفصل يعتمد على ما تعلمته في الفصول السابقة:
- المتغيرات تخزن القيم: `name = "Ahmad"`.
- الدالة `print()` تطبع القيم.
- النصوص توضع بين علامات اقتباس، والأرقام توضع بدونها.

## إحماء 🔥

توقّع المخرجات على ورقة أولًا، ثم شغّل الكود وقارن.

### إحماء 1

```python
print(type(95))
print(type("95"))
```

<details>
<summary>الحل</summary>

```text
<class 'int'>
<class 'str'>
```

الرقم `95` بدون اقتباس هو عدد صحيح (Integer). أما `"95"` بين الاقتباس فهو نص (String) حتى لو كان يبدو كرقم.
</details>

### إحماء 2

```python
x = 10
y = 3.14
print(type(x))
print(type(y))
```

<details>
<summary>الحل</summary>

```text
<class 'int'>
<class 'float'>
```

الأعداد التي تحتوي على فاصلة عشرية `.` تسمى أعدادًا عشرية (Float)، حتى لو كان الجزء العشري صفرًا مثل `5.0`.
</details>

### إحماء 3

```python
print(10 + 5)
print("10" + "5")
```

<details>
<summary>الحل</summary>

```text
15
105
```

الجمع بين الأعداد يجري عملية حسابية (15). أما الجمع بين النصوص فيجري عملية «دمج» (Concatenation) فيلصق النصين ببعضهما (105).
</details>

## التمارين

### تمرين 1 ⭐ — تعرّف على الأنواع

لديك المتغيرات التالية. استخدم الدالة `type()` لطباعة نوع كل متغير.

```python
student_name = "Omar"
student_age = 14
student_grade = 88.5
is_passed = True
```

💡 تلميح 1: الصيغة هي `type(variable_name)`.

💡 تلميح 2: ضع كل `print()` في سطر مستقل.

<details>
<summary>الحل المفصّل</summary>

```python
student_name = "Omar"
student_age = 14
student_grade = 88.5
is_passed = True

print(type(student_name))
print(type(student_age))
print(type(student_grade))
print(type(is_passed))
```

المخرجات:
```text
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
```
الدالة `type()` هي أفضل صديق لك عندما تشك في نوع البيانات الذي تتعامل معه.
</details>

---

### تمرين 2 ⭐ — أكمل التحويل

أكمل الفراغات لتحويل المتغير النصي إلى عدد صحيح وطباعته.

```python
grade_text = "90"
# grade_number حول النص إلى عدد صحيح وخزنه في المتغير 
grade_number = ____(____)
print(grade_number + 10)
```

المخرجات المتوقعة:

```text
100
```

💡 تلميح 1: الدالة التي تحول إلى عدد صحيح هي `int()`.

💡 تلميح 2: ضع المتغير `grade_text` بين قوسي الدالة.

<details>
<summary>الحل المفصّل</summary>

```python
grade_text = "90"
grade_number = int(grade_text)
print(grade_number + 10)
```

بدون التحويل `int()`، ستحاول بايثون جمع النص `"90"` مع العدد `10` وسيحدث خطأ. التحويل يستخرج القيمة الرقمية من النص.
</details>

### تمرين 3 ⭐⭐ — دمج النصوص مع الأعداد

لديك الكود التالي الذي يحاول طباعة رسالة طالب، لكنه يعطي خطأ. أصلح الكود باستخدام الدالة `str()`.

```python
student = "Ali"
grade = 85
print("Student " + student + " got " + grade + " points.")
```

💡 تلميح 1: الخطأ يحدث لأنك تحاول دمج (لصق) نص مع عدد.

💡 تلميح 2: لفّ المتغير `grade` بالدالة `str()` ليصبح نصًا قبل الدمج.

<details>
<summary>الحل المفصّل</summary>

```python
student = "Ali"
grade = 85
print("Student " + student + " got " + str(grade) + " points.")
```

بايثون صارمة جدًا regarding الأنواع. لا تسمح بجمع `str` مع `int` مباشرة. يجب تحويل العدد إلى نص صراحةً باستخدام `str()`.
</details>

---

### تمرين 4 ⭐⭐ — القسمة تُنتج عشرية

في بايثون 3، عملية القسمة `/` تُنتج دائمًا عددًا عشريًا (`float`) حتى لو كانت القسمة صحيحة. توقع المخرجات ثم تحقق باستخدام `type()`.

```python
result = 10 / 2
print(result)
print(type(result))
```

💡 تلميح 1: القسمة العادية تستخدم `/`.

💡 تلميح 2: حتى لو كانت النتيجة 5، كيف ستبدو؟

<details>
<summary>الحل المفصّل</summary>

```text
5.0
<class 'float'>
```

لماذا يعمل؟ صمم مطورو Python 3 القسمة `/` لتعيد دائمًا `float` للحفاظ على الدقة. إذا أردت عددًا صحيحًا، سنستخدم لاحقًا القسمة الصحيحة `//`.
</details>

### تمرين 5 ⭐⭐⭐ — حساب المجموع من نصوص

تخيل أن لدينا درجات مخزنة كنصوص (كما لو أننا قرأناها من ملف). احسب المجموع الكلي واطبعه.

```python
math_grade = "80"
science_grade = "90"

# المطلوب: تحويل الدرجات، جمعهما، وطباعة المجموع
```

المخرجات المتوقعة:

```text
170
```

💡 تلميح 1: لا يمكنك جمع `"80" + "90"` مباشرة لأن النتيجة ستكون `"8090"`.

💡 تلميح 2: حول كل متغير إلى `int()` داخل عملية الجمع أو قبلها.

<details>
<summary>الحل المفصّل</summary>

```python
math_grade = "80"
science_grade = "90"

total = int(math_grade) + int(science_grade)
print(total)
```

هنا قمنا بتحويل النص إلى أرقام قبل الجمع. هذا سينقذنا كثيرًا في مشروع دفتر الدرجات عندما نأخذ المدخلات من المستخدم (حيث تأتي دائمًا كنصوص).
</details>

### تمرين 6 ⭐⭐⭐ — الأعداد العشرية والدقة

لديك متوسط درجات مخزن كعدد عشري. حوّله إلى عدد صحيح (بدون فاصلة) واطبعه.

```python
average = 89.75
# حول المتوسط إلى عدد صحيح واطبعه
```

المخرجات المتوقعة:

```text
89
```

💡 تلميح 1: استخدم الدالة `int()` على العدد العشري.

💡 تلميح 2: الدالة `int()` لا تقرّب الرقم لأقرب عدد، بل «تقتطع» (truncate) الفاصلة العشرية وما بعدها.

<details>
<summary>الحل المفصّل</summary>

```python
average = 89.75
print(int(average))
```

لاحظ أن النتيجة `89` وليست `90`. الدالة `int()` تزيل الجزء العشري ببساطة. إذا أردت التقريب الرياضي، سنستخدم لاحقًا دالة `round()`.
</details>

### تمرين 7 ⭐⭐⭐⭐ — رسالة النجاح المنسقة

استخدم ما تعلمته لتوليد رسالة نجاح طالب. لديك المتغيرات التالية، ادمجها في جملة واحدة.

```python
name = "Salma"
score = 95.5
```

المخرجات المتوقعة:

```text
Congratulations Salma! Your score is 95.5
```

💡 تلميح 1: ستحتاج لدمج نصوص مع متغيرات.

💡 تلميح 2: المتغير `name` نصي بالفعل، لكن `score` عشري ويحتاج إلى تحويل `str()`.

<details>
<summary>الحل المفصّل</summary>

```python
name = "Salma"
score = 95.5

message = "Congratulations " + name + "! Your score is " + str(score)
print(message)
```

لماذا يعمل؟ حوّلنا `score` إلى نص لنتمكن من لصقه بباقي الجملة. في فصل «تنسيق النصوص» سنتعلم طريقة أسهل وأجمل بكثير لعمل هذا دون كل هذا الجمع!
</details>

### تمرين 8 ⭐⭐⭐⭐ — المنطق (Booleans)

القيم المنطقية (`True` و `False`) هي أساس اتخاذ القرارات في البرمجة. احفظ نتيجة المقارنات في متغيرات واطبع أنواعها.

```python
is_passed = 85 >= 50
is_failed = 40 == 50

print(is_passed)
print(is_failed)
# اطبع نوعهما
```

💡 تلميح 1: `>=` تعني «أكبر من أو يساوي»، و `==` تعني «هل يساوي؟».

💡 تلميح 2: استخدم `type()` على المتغيرين.

<details>
<summary>الحل المفصّل</summary>

```python
is_passed = 85 >= 50
is_failed = 40 == 50

print(is_passed) # True
print(is_failed) # False

print(type(is_passed)) # <class 'bool'>
print(type(is_failed)) # <class 'bool'>
```

المتغيرات المنطقية لا توضع بين علامات اقتباس. `True` و `False` كلمات محجوزة في بايثون (حرف أول كبير).
</details>

### تمرين 9 ⭐⭐⭐⭐⭐ — مشروع مصغّر: حاسبة المتوسط

لنبني الجزء الثاني من **دفتر الدرجات** 📚. 
لديك درجات ثلاث مواد مخزنة كنصوص (لأننا تخيلنا أن المستخدم أدخلها أو قرأناها من ملف).
1. حول الدرجات إلى أعداد عشرية (`float`).
2. احسب المجموع.
3. احسب المتوسط بقسمة المجموع على 3.
4. اطبع رسالة أخيرة توضح المتوسط كنص.

```python
arabic = "85.5"
math = "90.0"
science = "88.5"
```

💡 تلميح 1: استخدم `float()` بدلاً من `int()` لأن الدرجات تحتوي على فواصل عشرية.

💡 تلميح 2: احسب المتوسط، ثم استخدم `str()` لدمج النتيجة في رسالة الطباعة.

<details>
<summary>الحل المفصّل</summary>

```python
arabic = "85.5"
math = "90.0"
science = "88.5"

# التحويل
a_num = float(arabic)
m_num = float(math)
s_num = float(science)

# الحساب
total = a_num + m_num + s_num
average = total / 3

# الطباعة
print("Total Score: " + str(total))
print("Average: " + str(average))
```

المخرجات:
```text
Total Score: 264.0
Average: 88.0
```

هذا هو جوهر التعامل مع البيانات: نستقبلها بشكل ما (نصوص)، نعالجها (أرقام)، ثم نعرضها (نصوص).
</details>

## مختبر الأخطاء 🧪

في كل خطأ مما يلي: **توقّع نوع الخطأ ورسالته قبل قراءة الحل**، ثم قارن.

### 🧪 خطأ 1 — الجمع المستحيل

```python
age = 12
print("Age: " + age)
```

<details>
<summary>التحليل والإصلاح</summary>

المخرجات المتوقعة:

```text
TypeError: can only concatenate str (not "int") to str
```

الخطأ `TypeError` (خطأ في النوع). بايثون تخبرك بوضوح: «يمكنني فقط دمج النصوص مع النصوص، ولا يمكنني دمج النص مع العدد الصحيح».

الإصلاح: حول العدد إلى نص.

```python
age = 12
print("Age: " + str(age))
```
</details>

---

### 🧪 خطأ 2 — التحويل الخاطئ لعدد عشري

```python
grade_text = "95.5"
grade_num = int(grade_text)
print(grade_num)
```

<details>
<summary>التحليل والإصلاح</summary>

المخرجات المتوقعة:

```text
ValueError: invalid literal for int() with base 10: '95.5'
```

الخطأ `ValueError` (خطأ في القيمة). الدالة `int()` تتوقع رقمًا صحيحًا خاليًا من الفواصل العشرية. عندما رأت النقطة `.` رفضت التحويل.

الإصلاح: استخدم `float()` للنصوص العشرية، ثم حولها إلى `int()` لاحقًا إذا أردت التخلص من الفاصلة.

```python
grade_text = "95.5"
grade_num = float(grade_text) # يعمل بنجاح
print(grade_num)
```
</details>

---

### 🧪 خطأ 3 — تحويل نص غير رقمي

```python
name = "Ahmad"
print(int(name))
```

<details>
<summary>التحليل والإصلاح</summary>

المخرجات المتوقعة:

```text
ValueError: invalid literal for int() with base 10: 'Ahmad'
```

نفس نوع الخطأ `ValueError`. الدالة `int()` تحاول قراءة النص كأرقام، لكنها تعجز عن تحويل الحروف العربية أو الإنجليزية إلى أرقام.

الإصلاح: لا تحول الأسماء إلى أرقام! تأكد دائمًا أن المحتوى الذي تحوله يمثل رقمًا فعلاً.
</details>

## تحدي المتعة 🎮 — لعبة تخمين النوع

اكتب برنامجًا يعرّف 4 متغيرات غريبة، واطلب من نفسك (أو من زميلك) تخمين نوعها قبل طباعة `type()`.

```python
var1 = "100"
var2 = 100.0
var3 = "True"
var4 = False
```

<details>
<summary>الحل</summary>

```python
var1 = "100"      # str (لأنه بين اقتباس)
var2 = 100.0      # float (لأنه يحتوي على نقطة)
var3 = "True"     # str (لأنه بين اقتباس، وليس قيمة منطقية)
var4 = False      # bool (لأنه كلمة محجوزة بدون اقتباس)

print(type(var1))
print(type(var2))
print(type(var3))
print(type(var4))
```

الخدعة هنا هي أنAnything بين علامتي اقتباس هو `str` دائمًا، مهما كان شكله!
</details>

## أخطاء شائعة عند المبتدئين

1. **الخلط بين `"5"` و `5`**: الأول نص (String) ويمكن دمجه مع نصوص أخرى، والثاني رقم (Integer) ويمكن إجراء عمليات حسابية عليه.
2. **محاولة تحويل نص حرفي إلى رقم**: مثل `int("Ahmad")`، وهذا مستحيل منطقيًا ويطلق `ValueError`.
3. **نسيان تحويل المدخلات**: لاحقًا عندما نتعلم `input()`، تذكر أن كل ما يدخله المستخدم هو `str` ويجب تحويله إلى `int` أو `float` قبل الحساب.
4. **الكتابة `true` بحرف صغير**: القيم المنطقية في بايثون تبدأ بحرف كبير دائمًا: `True` و `False`.
5. **استخدام الفاصلة العربية في الأعداد العشرية**: مثل `85,5`. بايثون تستخدم النقطة الإنجليزية `.` فقط للأعداد العشرية: `85.5`.

## قائمة تحقق ✅

قبل الانتقال إلى الفصل التالي، تأكد أنك تستطيع:

- [ ] التمييز بين `int` و `float` و `str` و `bool`.
- [ ] استخدام `type()` لفحص المتغيرات.
- [ ] تحويل النصوص إلى أرقام باستخدام `int()` و `float()`.
- [ ] تحويل الأرقام إلى نصوص باستخدام `str()` لدمجها في جمل.
- [ ] فهم رسائل `TypeError` و `ValueError` وإصلاحها.

**ماذا سيعتمد عليه الفصل القادم؟** فصل «السلاسل النصية» سيعمّق فهمك للنصوص (`str`)، وستتعلم كيف تقتطع أجزاء منها، تبحث فيها، وتغير حروفها، وهو أمر جوهري لتنظيف أسماء الطلاب ومعالجة البيانات النصية في دفتر الدرجات.
