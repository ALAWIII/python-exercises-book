# العمليات المنطقية (البولينية)

## ماذا سنتقن؟

بنهاية هذا الفصل ستتمكن من:

1. استخدام عوامل المقارنة الستة: `==` و `!=` و `<` و `>` و `<=` و `>=`.
2. استخدام العوامل المنطقية: `and` و `or` و `not`.
3. تخزين القيم المنطقية `True` و `False` في متغيرات وطباعتها.
4. فهم جداول الحقيقة وتقييم التعبيرات المركبة خطوة خطوة.
5. إدراك كيف تتحكم القيم المنطقية في مسار البرنامج (معايرة تمهيدية).

📖 يقابل هذا الفصل: **الفصل 10 «العمليات المنطقية (البولينية)»** من كتاب «البرمجة بلغة بايثون».

## مراجعة سريعة

- الأعداد نوعان: `int` مثل 85، و `float` مثل 88.5.
- النصوص `str` توضع بين اقتباس: `"85"`.
- القيم المنطقية `bool` لها قيمتان فقط: `True` و `False` بحرف أول كبير دائمًا.
- دمج الأنواع المختلفة قد يطلق `TypeError`.

توقّع المخرجات على ورقة أولًا، ثم شغّل الكود وقارن.

## التمارين

### تمرين 1 ⭐ — هل نجح الطالب؟

درجة النجاح 60. خزّن درجة طالب (65) في متغير، ثم خزّن نتيجة المقارنة `الدرجة >= 60` في متغير `is_passed` واطبعه.

المخرجات المتوقعة:

```text
True
```

💡 تلميح 1: «أكبر من أو يساوي» يُكتب `>=`.

💡 تلميح 2: يمكنك وضع المقارنة مباشرة يمين إشارة الإسناد.

<details>
<summary>الحل المفصّل</summary>

```python
grade = 65
is_passed = grade >= 60
print(is_passed)
```

لماذا يعمل؟ التعبير `grade >= 60` يُقيَّم أولًا فينتج `True`، ثم تُخزَّن هذه القيمة المنطقية في المتغير `is_passed`. هذا النمط (تخزين نتيجة شرط في متغير) سنستخدمه كثيرًا في دفتر الدرجات.
</details>

### تمرين 2 ⭐ — أكمل الفراغ

أكمل الفراغ بعامل المقارنة الصحيح بحيث يكون الناتج `True`:

```python
a = 10
b = 20
print(a ____ b)
```

💡 تلميح 1: أي علاقة بين 10 و 20 صحيحة؟

💡 تلميح 2: هناك أكثر من إجابة صحيحة!

<details>
<summary>الحل المفصّل</summary>

```python
a = 10
b = 20
print(a < b)   # True
print(a != b)  # True أيضًا
```

كل من `<` و `!=` و `<=` يعطي `True` هنا. المهم أن تفهم أن عوامل المقارنة تسأل سؤالًا وتجيب بـ `True` أو `False`.
</details>

### تمرين 3 ⭐⭐ — مقارنة الأسماء

لديك اسمان:

```python
name1 = "Salma"
name2 = "salma"
```

اطبع نتيجة `name1 == name2` ثم نتيجة `name1 != name2`. فسر النتيجة في تعليق.

المخرجات المتوقعة:

```text
False
True
```

💡 تلميح 1: بايثون حساسة لحالة الأحرف في النصوص.

💡 تلميح 2: `S` الكبيرة تختلف عن `s` الصغيرة.

<details>
<summary>الحل المفصّل</summary>

```python
name1 = "Salma"
name2 = "salma"

print(name1 == name2)  # False
print(name1 != name2)  # True

# Python is case-sensitive: 'S' and 's' are different characters
```

هذا سلوك مهم في دفتر الدرجات: إذا أدخل طالب اسمه بحروف مختلفة عن المسجل، لن يتعرف النظام عليه. الحل تعلمناه في فصل السلاسل: `lower()` على الاسمين قبل المقارنة.
</details>

### تمرين 4 ⭐⭐ — الترتيب الأبجدي

توقّع ثم تحقق: ماذا تُرجع `"Ali" < "Omar"`؟ ولماذا؟

المخرجات المتوقعة:

```text
True
```

💡 تلميح 1: مقارنة النصوص تتم حرفًا حرفًا من اليسار.

💡 تلميح 2: قارن الحرف الأول من كل اسم.

<details>
<summary>الحل المفصّل</summary>

```python
print("Ali" < "Omar")  # True
```

بايثون تقارن النصوص حسب أرقام الحروف في جدول يونيكود، حرفًا حرفًا. الحرف `A` رقمه أصغر من `O`، لذلك `"Ali"` تسبق `"Omar"` أبجديًا والنتيجة `True`. هذا مفيد لاحقًا لترتيب قوائم الطلاب أبجديًا.
</details>

### تمرين 5 ⭐⭐⭐ — جدول الحقيقة

أكمل الجدول التالي يدويًا، ثم تحقق بتشغيل الكود:

| التعبير | النتيجة؟ |
|---|---|
| `True and True` | ؟ |
| `True and False` | ؟ |
| `False or True` | ؟ |
| `False or False` | ؟ |
| `not True` | ؟ |
| `not False` | ؟ |

💡 تلميح 1: `and` تتطلب صحّتين، و `or` تكتفي بواحدة.

💡 تلميح 2: `not` تقلب القيمة.

<details>
<summary>الحل المفصّل</summary>

```python
print(True and True)    # True
print(True and False)   # False
print(False or True)    # True
print(False or False)   # False
print(not True)         # False
print(not False)        # True
```

القاعدة الذهبية:
- `and`: خطأ واحد يكفي ليكون الناتج `False`.
- `or`: صح واحد يكفي ليكون الناتج `True`.
- `not`: يعكس القيمة.

احفظ هذا الجدول؛ ستحتاجه في كل شرط تكتبه.
</details>

### تمرين 6 ⭐⭐⭐ — درجة الشرف

يُمنح الطالب درجة الشرف إذا كانت درجته 90 فأكثر. خزّن درجة طالب ثم أنشئ متغيرًا منطقيًا `has_honors` يعبر عن ذلك واطبعه. جرّب مرة بالدرجة 92 ومرة بالدرجة 88.

المخرجات المتوقعة:

```text
True
False
```

💡 تلميح 1: «90 فأكثر» تعني `>=` وليس `>`.

💡 تلميح 2: أعد إسناد المتغير `grade` بين التجربتين.

<details>
<summary>الحل المفصّل</summary>

```python
grade = 92
has_honors = grade >= 90
print(has_honors)  # True

grade = 88
has_honors = grade >= 90
print(has_honors)  # False
```

لاحظ كيف أن المتغير المنطقي يتغير تلقائيًا حسب القيمة الحالية لـ `grade` في كل مرة نعيد فيها التقييم.
</details>

### تمرين 7 ⭐⭐⭐ — النجاح في المادتين معًا

لا ينتقل الطالب إلى المستوى التالي إلا إذا نجح في الرياضيات والعلوم معًا (درجة النجاح 50). درجات طالب: الرياضيات 70، العلوم 45. أنشئ متغير `promoted` واطبعه.

المخرجات المتوقعة:

```text
False
```

💡 تلميح 1: نحتاج شرطين معًا — أي عامل منطقي نستخدم؟

💡 تلميح 2: ضع كل مقارنة بين قوسين للوضوح.

<details>
<summary>الحل المفصّل</summary>

```python
math = 70
science = 45

promoted = (math >= 50) and (science >= 50)
print(promoted)
```

التقييم: `70 >= 50` صحيحة، لكن `45 >= 50` خاطئة. وبما أن `and` تتطلب صحّتين، فالنتيجة `False`. الطالب بحاجة إلى إعادة العلوم.
</details>

### تمرين 8 ⭐⭐⭐⭐ — الغياب والأهلية

شروط دخول الاختبار: ألا يكون الطالب محرومًا **و** أن تكون درجته في الأعمال 50 فأكثر. لديك:

```python
is_absent = False
coursework = 75
```

أنشئ متغير `can_take_exam` بالشرطين واطبعه. ثم غيّر `is_absent` إلى `True` وتنبأ بالنتيجة الجديدة.

المخرجات المتوقعة:

```text
True
False
```

💡 تلميح 1: «ألا يكون محرومًا» تعني نفي القيمة: `not`.

💡 تلميح 2: ادمج النفي مع `and`.

<details>
<summary>الحل المفصّل</summary>

```python
is_absent = False
coursework = 75

can_take_exam = (not is_absent) and (coursework >= 50)
print(can_take_exam)  # True

is_absent = True
can_take_exam = (not is_absent) and (coursework >= 50)
print(can_take_exam)  # False
```

التقييم الأول: `not False` تعطي `True`، و `75 >= 50` صحيحة، فيكون الناتج `True`. في الحالة الثانية: `not True` تعطي `False`، فيصبح الناتج `False` مهما كانت درجة الأعمال — وهذا بالضبط منطق الحرمان.
</details>

### تمرين 9 ⭐⭐⭐⭐ — تقييم تعبير مركب خطوة خطوة

قيّم التعبير التالي يدويًا خطوة خطوة (اكتب الخطوات في تعليقات)، ثم تحقق بالتشغيل:

```python
print(not ((9 > 7) and (2 < 4)))
```

💡 تلميح 1: ابدأ بما داخل الأقواس العميقة أولًا.

💡 تلميح 2: طبّق `and` ثم طبّق `not` في النهاية.

<details>
<summary>الحل المفصّل</summary>

```python
# Step 1: (9 > 7) is True
# Step 2: (2 < 4) is True
# Step 3: True and True is True
# Step 4: not True is False

print(not ((9 > 7) and (2 < 4)))
```

المخرجات:

```text
False
```

هذه المهارة (التقييم خطوة خطوة) هي بالضبط ما يفعله المبرمج عند قراءة شرط معقد في برنامج كبير.
</details>

### تمرين 10 ⭐⭐⭐⭐⭐ — مشروع مصغّر: تقرير حالة الطالب

لنبني الجزء المنطقي من **دفتر الدرجات** 📚. لديك بيانات طالب:

```python
grade = 92
absences = 2
```

احسب واطبع ثلاث نتائج منطقية، كل واحدة في سطر:

1. `is_passed`: هل الدرجة 50 فأكثر؟
2. `has_honors`: هل الدرجة 90 فأكثر؟
3. `scholarship_eligible`: هل الدرجة 90 فأكثر **و** الغياب 3 أيام أو أقل؟

المخرجات المتوقعة:

```text
True
True
True
```

💡 تلميح 1: احسب كل شرط في متغير مستقل قبل الطباعة.

💡 تلميح 2: الشرط الثالث يدمج `>=` مع `and`.

<details>
<summary>الحل المفصّل</summary>

```python
grade = 92
absences = 2

is_passed = grade >= 50
has_honors = grade >= 90
scholarship_eligible = (grade >= 90) and (absences <= 3)

print(is_passed)
print(has_honors)
print(scholarship_eligible)
```

جرّب الآن تغيير `grade` إلى 85: ماذا تتوقع؟ ستصبح المخرجات `True` ثم `False` ثم `False` — الطالب ناجح لكنه فقد الشرف والمنحة. في الوحدة القادمة سنجعل البرنامج يطبع رسائل مختلفة تلقائيًا حسب هذه النتائج باستخدام `if`.
</details>

## مختبر الأخطاء 🧪

في كل خطأ مما يلي: **توقّع نوع الخطأ ورسالته قبل قراءة الحل**، ثم قارن.

### 🧪 خطأ 1 — مقارنة نص بعدد

```python
grade = "85"
print(grade >= 50)
```

<details>
<summary>التحليل والإصلاح</summary>

المخرجات المتوقعة:

```text
Traceback (most recent call last):
  File "check.py", line 2, in <module>
    print(grade >= 50)
TypeError: '>=' not supported between instances of 'str' and 'int'
```

السبب: `grade` نص `"85"` (بين اقتباس)، ولا يجوز في بايثون مقارنة نص بعدد بـ `>=`. رسالة الخطأ واضحة: العامل غير مدعوم بين `str` و `int`.

الإصلاح: حوّل النص إلى عدد أولًا:

```python
grade = "85"
print(int(grade) >= 50)  # True
```
</details>

---

### 🧪 خطأ 2 — إسناد بدلًا من مقارنة

```python
grade = 85
if grade = 90:
    print("Excellent")
```

<details>
<summary>التحليل والإصلاح</summary>

المخرجات المتوقعة:

```text
  File "check.py", line 2
    if grade = 90:
       ^^^^^^^^^^
SyntaxError: invalid syntax
```

(في Python 3.12+ قد تضيف الرسالة اقتراحًا مثل: `Maybe you meant '==' or ':=' instead of '='?`)

السبب: علامة `=` تعني الإسناد (ضع القيمة هنا)، ولا يصح استخدامها داخل شرط. المقارنة تحتاج علامتي يساوٍ `==`.

> ملاحظة: جملة `if` سنشرحها بالتفصيل في الوحدة القادمة، لكن هذا الخطأ شائع جدًا لدرجة أنه يستحق المعاينة مبكرًا.

الإصلاح:

```python
grade = 85
if grade == 90:
    print("Excellent")
```
</details>

### 🧪 خطأ 3 — AND بحروف كبيرة

```python
print(True AND False)
```

<details>
<summary>التحليل والإصلاح</summary>

المخرجات المتوقعة:

```text
Traceback (most recent call last):
  File "logic.py", line 1, in <module>

```

السبب: الكلمات المفتاحية في بايثون تُكتب بحروف صغيرة دائمًا: `and` و `or` و `not`. عندما كتبت `AND` ظنت بايثون أنك تبحث عن متغير اسمه `AND` فلم تجده.

الإصلاح:

```python
print(True and False)  # False
```
</details>

## تحدي المتعة 🎮 — خدع منطقية

توقّع ناتج كل تعبير قبل تشغيله — اثنان منها سيخدعانك على الأرجح:

```python
print(not not True)
print(True or False and False)
print(0 == False)
```

<details>
<summary>الحل</summary>

```text
True
True
True
```

التفسير:

1. `not not True`: النفي الأول يقلبها إلى `False`، والثاني يعيدها `True`. النفي المزدوج يعيد القيمة الأصلية.
2. `True or False and False`: العامل `and` له أولوية أعلى من `or`، فيُقيَّم `False and False` أولًا (= `False`)، ثم `True or False` = `True`. الأقواس تزيل أي لبس: `True or (False and False)`.
3. `0 == False`: بايثون تعتبر الصفر مساويًا لمنطقيًا للخاطئ. هذه معلومة متقدمة تفيدك لاحقًا في اختبارات القيم الفارغة.
</details>

## أخطاء شائعة عند المبتدئين

1. **الخلط بين `=` و `==`**: الأولى للإسناد والثانية للمقارنة. هذا أشهر خطأ على الإطلاق، وسترى له علاجًا عمليًا في فصل الشروط.
2. **كتابة `true` أو `TRUE` أو `True` بأحرف خاطئة**: القيم المنطقية في بايثون تُكتب `True` و `False` بحرف أول كبير فقط.
3. **استخدام `AND` و `OR` و `NOT` بحروف كبيرة**: بايثون تفهم فقط `and` و `or` و `not` الصغيرة.
4. **مقارنة نص بعدد**: `"85" >= 50` تطلق `TypeError`. حوّل أولًا بـ `int()`.
5. **الاعتقاد أن `"5" == 5` صحيحة**: نص `"5"` لا يساوي العدد 5 أبدًا؛ النوعان مختلفان.
6. **نسيان الأقواس في الشروط المركبة**: `(a >= 50) and (b >= 50)` أوضح وأأمن من كتابتها بلا أقواس.

## قائمة تحقق ✅

قبل الانتقال إلى الوحدة التالية، تأكد أنك تستطيع:

- [ ] كتابة عوامل المقارنة الستة وتوقع نتائجها.
- [ ] استخدام `and` و `or` و `not` وتفسير نتائجها بجداول الحقيقة.
- [ ] تخزين نتائج المقارنات في متغيرات منطقية.
- [ ] تقييم تعبير مركب خطوة خطوة.
- [ ] تمييز أخطاء `=` مقابل `==` و `AND` مقابل `and`.

**ماذا سيعتمد عليه الفصل القادم؟** وحدة «التحكم بالتدفق» تبدأ بفصل **التعليمات الشرطية**: كل ما تعلمته هنا سيُستخدم مباشرة — سنكتب `if grade >= 65:` ونترك لبَايثون قرار طباعة «ناجح» أو «راسب» حسب النتيجة المنطقية.
