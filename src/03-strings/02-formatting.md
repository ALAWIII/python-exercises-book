# تنسيق النصوص

## ماذا سنتقن؟

بنهاية هذا الفصل ستتمكن من:

1. كتابة نصوص متعددة الأسطر واستخدام محارف الهروب (Escape Characters) مثل `n\` و `t\`.
2. تضمين علامات الاقتباس داخل النصوص باستخدام التهريب أو علامات الاقتباس المختلفة.
3. استخدام الدالة `()str.format` لإدراج المتغيرات داخل النصوص بدقة.
4. التحكم في محاذاة النصوص (Alignment) وتحديد دقة الأعداد العشرية (Precision).

📖 يقابل هذا الفصل: **الفصل 8 «تنسيق النصوص»** من كتاب «البرمجة بلغة بايثون».

## مراجعة سريعة

- النصوص توضع بين `" "` أو `' '`.
- لدمج متغير نصي مع نص ثابت نستخدم `+`.
- لدمج رقم مع نص يجب تحويله أولاً باستخدام `()str`.
- الدالة `()print` تضيف سطرًا جديدًا تلقائيًا في النهاية.

## إحماء 🔥

توقّع المخرجات على ورقة أولًا، ثم شغّل الكود وقارن.

### إحماء 1

```python
print("Line 1\nLine 2")
```

<details>
<summary>الحل</summary>

```text
Line 1
Line 2
```

المحرف `n\` يعني "سطر جديد" (Newline).
</details>

### إحماء 2

```python
print("Name: {}, Grade: {}".format("Ali", 95))
```

<details>
<summary>الحل</summary>

```text
Name: Ali, Grade: 95
```

الدالة `()format` تستبدل الأقواس `{}` بالقيم الممررة إليها بالترتيب.
</details>

### إحماء 3

```python
print("{:.2f}".format(85.678))
```

<details>
<summary>الحل</summary>

```text
85.68
```

الرمز `:.2f` يخبر بايثون ب تنسيق العدد كعشري (float) مع عرض منزلتين عشريتين فقط، وتقريب الرقم.
</details>

## التمارين

### تمرين 1 ⭐ — طباعة متعددة الأسطر

اكتب برنامجًا يطبع بطاقة طالب بسيطة تحتوي على ثلاثة أسطر (الاسم، الصف، المدرسة) باستخدام محرف الهروب `n\` داخل استدعاء `print` واحد.

💡 تلميح 1: ضع `n\` بين كل معلومة والأخرى.

💡 تلميح 2: تأكد من وضع كل النص بين علامتي اقتباس.

<details>
<summary>الحل المفصّل</summary>

```python
print("Name: Omar\nClass: 8-A\nSchool: Al-Noor")
```
</details>

### تمرين 2 ⭐ — علامات الاقتباس الداخلية

اطبع الجملة التالية بالضبط، بما في ذلك علامات الاقتباس المزدوجة حول كلمة "Math":
`The student excels in "Math" this year.`

💡 تلميح 1: استخدم علامات اقتباس مفردة `' '` لتغليف النص الكامل.

💡 تلميح 2: أو استخدم محرف الهروب `\"` داخل العلامات المزدوجة.

<details>
<summary>الحل المفصّل</summary>

```python
print('The student excels in "Math" this year.')
# أو
print("The student excels in \"Math\" this year.")
```
</details>

### تمرين 3 ⭐⭐ — الإدراج باستخدام format

استخدم الدالة `.()format` لطباعة رسالة تهنئة للطالب، حيث يتم إدراج اسمه ودرجته في الأماكن المخصصة.

```python
student = "Salma"
grade = 92
# أكمل السطر التالي:
# print("Congratulations {}! You scored {}.".____)
```

💡 تلميح 1: استدعِ الدالة `()format` بعد النص مباشرة.

💡 تلميح 2: مرّر المتغيرين بالترتيب داخل أقواس `()format`.

<details>
<summary>الحل المفصّل</summary>

```python
student = "Salma"
grade = 92
print("Congratulations {}! You scored {}.".format(student, grade))
```
</details>

---

### تمرين 4 ⭐⭐ — دقة الأعداد العشرية

متوسط درجات الطالب هو `88.756`. اطبعه في جملة بحيث يظهر بمنزلة عشرية واحدة فقط (مقربًا).

```python
average = 88.756
```

المخرجات المتوقعة:

```text
Your average is 88.8
```

💡 تلميح 1: استخدم `{}` مع محدد التنسيق داخلها.

💡 تلميح 2: الصيغة هي `{1f.:}`.

<details>
<summary>الحل المفصّل</summary>

```python
average = 88.756
print("Your average is {:.1f}".format(average))
```
</details>

---

### تمرين 5 ⭐⭐⭐ — جدول بسيط (المحاذاة)

لديك طالبان ودرجاتهما. اطبعهما في جدول بحيث يكون الاسم في حقل عرضه 10 حروف، والدرجة في حقل عرضه 5 حروف.

```python
name1, grade1 = "Ali", 85
name2, grade2 = "Omar", 92
```

💡 تلميح 1: لتحديد العرض، نضع الرقم بعد النقطتين مثل `{10:}`.

💡 تلميح 2: كرر العملية للطالب الثاني.

<details>
<summary>الحل المفصّل</summary>

```python
name1, grade1 = "Ali", 85
name2, grade2 = "Omar", 92

print("{:10} {:5}".format("Name", "Grade"))
print("-" * 15)
print("{:10} {:5}".format(name1, grade1))
print("{:10} {:5}".format(name2, grade2))
```
هذا يجعل الأعمدة مصطفة بشكل مرتب جدًا، وهو أساس التقارير المدرسية.
</details>

### تمرين 6 ⭐⭐⭐ — الحشو (Padding)

اطبع اسم الطالب `"Ahmad"` في حقل عرضه 20 حرفًا، على أن تكون المساحة الفارغة مملوءة بنجوم `*` ويكون الاسم في المنتصف.

💡 تلميح 1: رمز التوسيط هو `^`.

💡 تلميح 2: الصيغة الكاملة هي `{20^*:}`.

<details>
<summary>الحل المفصّل</summary>

```python
print("{:*^20}".format("Ahmad"))
```
المخرجات: `*******Ahmad********`
</details>

---

### تمرين 7 ⭐⭐⭐⭐ — إعادة ترتيب الوسائط

في بعض الأحيان نحتاج لتغيير ترتيب الكلمات حسب اللغة. استخدم الفهارس داخل `{}` لطباعة الجملة التالية بترتيب معكوس للوسائط الممررة.

```python
# الوسائط الممررة: "Math", "Ali"
# المطلوب طباعته: "Ali studies Math"
```

💡 تلميح 1: الوسيط الأول فهرسه `0` والثاني فهرسه `1`.

💡 تلميح 2: اكتب `{1}` لطباعة الوسيط الثاني أولاً.

<details>
<summary>الحل المفصّل</summary>

```python
print("{1} studies {0}".format("Math", "Ali"))
```
</details>

### تمرين 8 ⭐⭐⭐⭐⭐ — مشروع مصغّر: التقرير المدرسي المنسق

لنبني التقرير النهائي لـ **دفتر الدرجات** 📚 باستخدام كل ما تعلمناه.
لديك المتغيرات التالية. اطبع تقريرًا محاطًا بإطار من النجوم، يحتوي على اسم الطالب، مادته، ودرجته العشرية بمنزلتين، مع محاذاة احترافية.

```python
student = "Layla"
subject = "Science"
score = 94.567
```

💡 تلميح 1: استخدم `30^*` لرسم الإطار العلوي والسفلي.

💡 تلميح 2: استخدم `{10:}` لمحاذاة العناوين مع القيم.

<details>
<summary>الحل المفصّل</summary>

```python
student = "Layla"
subject = "Science"
score = 94.567

border = "{:*^30}".format(" REPORT ")
print(border)
print("Name: {:<10} {}".format("", student))
print("Subject: {:<7} {}".format("", subject))
print("Score: {:<9} {:.2f}".format("", score))
print("*" * 30)
```
هذا التنسيق يجعل البرنامج يبدو كتطبيق حقيقي وليس مجرد نصوص عشوائية!
</details>

## مختبر الأخطاء 🧪

### 🧪 خطأ 1 — فهرس الوسيط غير موجود

```python
print("{1} got {2}".format("Ali", 90))
```

<details>
<summary>التحليل والإصلاح</summary>

المخرجات المتوقعة:
```text
IndexError: Replacement index 1 out of range for positional args tuple
```
(أو `tuple index out of range` في الإصدارات الأقدم).
السبب: مرّرنا وسيطين فقط (فهارسهما 0 و 1)، لكننا طلبنا الفهرس 2 في النص.
الإصلاح: راجع الفهارس، يجب أن تكون `{0}` و `{1}`.
</details>

---

### 🧪 خطأ 2 — رمز التنسيق الخاطئ

```python
average = 85.5
print("Average: {:d}".format(average))
```

<details>
<summary>التحليل والإصلاح</summary>

المخرجات المتوقعة:
```text
ValueError: Unknown format code 'd' for object of type 'float'
```
السبب: الرمز `d` مخصص للأعداد الصحيحة (integers)، لكن المتغير `average` هو عدد عشري (float).
الإصلاح: استخدم `f` للأعداد العشرية، أو حول المتغير إلى `int` قبل التنسيق.
</details>

---

### 🧪 خطأ 3 — النص غير المنتهي

```python
print("Student name: Ali)
```

<details>
<summary>التحليل والإصلاح</summary>

المخرجات المتوقعة:
```text
SyntaxError: unterminated string literal (detected at line 1)
```
السبب: نسيت إغلاق علامة الاقتباس في نهاية النص.
الإصلاح: أضف `"` في نهاية السطر.
</details>

## تحدي المتعة 🎮 — رسم صندوق نصي

استخدم ضرب النصوص `*` والتنسيق لرسم صندوق مغلق حول اسم الطالب `"Omar"`، بحيث يكون عرضه 20 حرفًا.

<details>
<summary>الحل</summary>

```python
name = "Omar"
width = 20

print("*" * width)
print("*" + "{:^{}}".format(name, width - 2) + "*")
print("*" * width)
```
</details>

## أخطاء شائعة عند المبتدئين

1. **نسيان النقطة قبل `()format`**: كتابة `print("{}".format())` صحيحة، لكن `print("{}"format())` تعطي خطأ `SyntaxError`.
2. **الخلط بين الأقواس**: الأقواس المعقوفة `{}` للحجز داخل النص، والأقواس العادية `()` لتمرير الوسائط للدالة.
3. **محاولة استخدام `+` مع الأعداد في `print`**: `print("Score: " + 90)` خطأ، استخدم `()format` لتجنب مشاكل التحويل.
4. **نسيان محرف الهروب `\`**: عند محاولة طباعة مسارات ملفات ويندوز مثل `"C:\new_folder"`، يتم تفسير `n\` كسطر جديد. الحل: استخدم الخام `r"C:\new_folder"` أو شرطتين مائلتين `\\`.
