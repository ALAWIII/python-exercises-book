# أول برنامج بايثون والتعليقات

## ماذا سنتقن؟

بنهاية هذا الفصل ستتمكن من:

1. كتابة أول سطر برمجي بلغة بايثون باستخدام الدالة ``print()``.
2. فهم كيفية حفظ الملفات بامتداد `.py` وتشغيلها.
3. كتابة التعليقات السطرية (`#`) والكتلية لشرح الكود.
4. استخدام التعليقات لتعطيل (Comment out) أجزاء من الكود لغرض الاختبار والبحث عن الأخطاء.

📖 يقابل هذا الفصل: **الفصل 4 «التعليقات واستخداماتها»** من كتاب «البرمجة بلغة بايثون» (مع تعويض الفصول التمهيدية 1-3 غير الموجودة في المقتطف).

## مراجعة سريعة

هذا هو فصل الانطلاق، لذا لا توجد مفاهيم برمجية سابقة نعتمد عليها. كل ما نحتاجه هو:
- تثبيت Python 3 على جهازك.
- فتح محرر نصوص (مثل VS Code أو Notepad++ أو حتى المفكرة).
- حفظ الملف بامتداد `.py` (مثلاً `school.py`).
- تشغيل الملف من الطرفية (Terminal / Command Prompt) باستخدام الأمر: `python school.py`.

## التمارين

### تمرين 1 ⭐ — أول طباعة

اكتب برنامجًا يطبع العبارة التالية بالضبط:

```text
My First Python Program
```

💡 تلميح 2: لا تنسَ وضع النص بين علامتي اقتباس `" "` أو `' '`.

<details>
<summary>الحل المفصّل</summary>

```python
print("My First Python Program")
```

لماذا يعمل؟ الدالة ``print()`` هي الأمر المسؤول عن إظهار النص على الشاشة، وعلامات الاقتباس تخبر بايثون أن هذا «نص» (String) وليس اسم متغير.

### تمرين 2 ⭐ — بطاقة طالب بسيطة

اكتب برنامجًا يطبع بطاقة طالب تحتوي على اسم الطالب وصفه، كل معلومة في سطر.

المخرجات المتوقعة:


💡 تلميح 1: ستحتاج إلى استدعاء الدالة `print()` مرتين.

💡 تلميح 2: كل استدعاء لـ `print()` يضع النص في سطر جديد تلقائيًا.

<details>
<summary>الحل المفصّل</summary>

```python
print("Name: Ahmad")
print("Class: 7-B")
```

بايثون تنفذ الأوامر من الأعلى إلى الأسفل. تطبع السطر الأول، ثم تنزل سطرًا وتطبع الثاني.
</details>

### تمرين 3 ⭐⭐ — أضف التعليقات

لديك الكود التالي الذي يطبع معلومات مدرسة. أضف تعليقًا سطريًا (Block Comment) فوق كل `print` يشرح ما يفعله هذا السطر.

```python
print("Al-Noor School")
print("Established: 2010")
print("Students: 500")
```

💡 تلميح 1: التعليق السطري يبدأ بعلامة `#` ويوضع في سطر مستقل قبل الكود.

💡 تلميح 2: اجعل التعليق واضحًا ومختصرًا، مثل: `# Print school name`.

<details>
<summary>الحل المفصّل</summary>

```python
# Print school name
print("Al-Noor School")

# Print establishment year
print("Established: 2010")

# Print number of students
print("Students: 500")
```

التعليقات لا تؤثر على تنفيذ البرنامج أبدًا، لكنها تجعل الكود مفهومًا لك ولأي مبرمج يقرأه لاحقًا.
</details>

---

### تمرين 4 ⭐⭐ — تعطيل الكود (Commenting Out)

لديك الكود التالي، لكنك تريد مؤقتًا إخفاء طباعة الدرجة القديمة لاختبار البرنامج بدونها، دون حذف السطر نهائيًا. عدّل السطر المناسب.

```python
print("Student: Omar")
print("Old Grade: 60")
print("New Grade: 85")
```

المخرجات المتوقعة:

```text
Student: Omar
New Grade: 85
```

💡 تلميح 1: لا تحذف السطر باستخدام مفتاح الحذف (Backspace).

💡 تلميح 2: ضع علامة `#` في بداية السطر الذي تريد تعطيله.

<details>
<summary>الحل المفصّل</summary>

```python
print("Student: Omar")
# print("Old Grade: 60")
print("New Grade: 85")
```

هذه technique (تقنية) مهمة جدًا تسمى "Commenting out". نستخدمها عند تجربة بدائل مختلفة أو عند البحث عن سطر يسبب خطأً في البرنامج.
</details>

---

### تمرين 5 ⭐⭐⭐ — بطاقة الطالب المعلقة

اكتب برنامجًا يطبع بطاقة طالب كاملة (الاسم، العمر، المادة، الدرجة). استخدم تعليقًا كتليًا (Block Comment) في بداية البرنامج يشرح الغرض منه، واستخدم تعليقات سطرية (Inline comments) بجوار الدرجات لتوضيح أنها درجات نهائية.

المخرجات المتوقعة:

```text
Name: Salma
Age: 14
Subject: Math
Final Grade: 92
```

💡 تلميح 1: التعليق الكتلي يوضع في أسطر مستقلة تبدأ بـ `#`.

💡 تلميح 2: التعليق السطري يوضع في نفس السطر بعد الكود، مفصولًا بمسافتين على الأقل.

<details>
<summary>الحل المفصّل</summary>

```python
# This program prints a student's report card
# Author: Python Student
# Date: 2024

print("Name: Salma")
print("Age: 14")
print("Subject: Math")
print("Final Grade: 92") # This is the final exam score
```

الكتاب المرجعي ينصح بأن تكتب التعليقات لتشرح «لماذا» (Why) يفعل الكود شيئًا ما، وليس «ماذا» (What) يفعل، لأن الكود نفسه يشرح الـ What.
</details>

### تمرين 6 ⭐⭐⭐ — البحث عن الخطأ بالتعطيل

الكود التالي يحتوي على خطأ في أحد الأسطر يمنع البرنامج من العمل (سنرى أنواع الأخطاء لاحقًا). استخدم تقنية «التعطيل» `#` لتكتشف أي سطر هو السطر المخالف، ثم أصلحه.

```python
print("Starting the grade system...")
print("Loading student data..."
print("System is ready!")
```

💡 تلميح 1: إذا شغّلت الكود الآن، سيظهر لك خطأ `SyntaxError`.

💡 تلميح 2: عطّل السطور واحدًا تلو الآخر حتى يعمل البرنامج، لتعرف أين المشكلة.

<details>
<summary>الحل المفصّل</summary>

السطر الثاني ينقصه قوس الإغلاق `)`. عندما نعطّل السطور سنكتشف أن السطر الثاني هو السبب.

الكود بعد الإصلاح:

```python
print("Starting the grade system...")
print("Loading student data...") # Added the missing closing parenthesis
print("System is ready!")
```

تعطيل الكود سطرًا سطرًا هو إحدى أقدم وأفضل طرق البحث عن الأخطاء (Debugging) التي يستخدمها المبرمجون المحترفون.
</details>

### تمرين 7 ⭐⭐⭐⭐ — مشروع مصغّر: بطاقة مدرسية منسقة

لنبدأ ببناء **المشروع التراكمي: دفتر درجات الصف** 📚. 
اكتب برنامجًا يحتوي على:
1. تعليق كتلي في الأعلى يشرح أن هذا البرنامج لإدارة درجات الصف.
2. طباعة عنوان كبير للبطاقة (مثل `--- Student Card ---`).
3. طباعة اسم الطالب، صفه، ومدرسته.
4. طباعة خط فاصل في النهاية.
5. تعطيل (Comment out) سطر طباعة المدرسة مؤقتًا لأننا سنضيفه لاحقًا بطريقة أخرى.

💡 تلميح 1: استخدم الرموز مثل `-` أو `*` لرسم الخطوط الفاصلة.

💡 تلميح 2: تأكد من أن كل النصوص بين علامات اقتباس.

<details>
<summary>الحل المفصّل</summary>

```python
# ==========================================
# School Gradebook System
# This script prints a single student card.
# ==========================================

print("--- Student Card ---")
print("Name: Ahmad")
print("Class: 8-A")
# print("School: Al-Noor") # Disabled for now, will be added later
print("--------------------")
```

هذا هو الهيكل الأولي لمشروعنا. في الفصول القادمة، سنستبدل هذه النصوص الثابتة بمتغيرات تتغير ديناميكيًا!
</details>

## مختبر الأخطاء 🧪

في كل خطأ مما يلي: **توقّع نوع الخطأ وسببه قبل قراءة الحل**، ثم قارن.

### 🧪 خطأ 1 — النص المكشوف

```python
print(Hello World)
```

<details>
<summary>التحليل والإصلاح</summary>

المخرجات المتوقعة:

```text
  File "test.py", line 1
    print(Hello World)
          ^^^^^^^^^^^
SyntaxError: invalid syntax. Perhaps you forgot a comma?
```

هذا خطأ تركيبي `SyntaxError`. بايثون لا تفهم النصوص إلا إذا كانت محاطة بعلامات اقتباس. عندما رأت `Hello` ظنت أنه اسم متغير، ثم رأت `World` بجانبه بدون فاصلة أو عامل جمع، فارتبكت.

الإصلاح: ضع النص بين علامتي اقتباس.

```python
print("Hello World")
```
</details>

---

### 🧪 خطأ 2 — الاقتباس الناقص

```python
print("Student Name: Omar)
```

<details>
<summary>التحليل والإصلاح</summary>

المخرجات المتوقعة:

```text
  File "test.py", line 1
    print("Student Name: Omar)
          ^
SyntaxError: unterminated string literal (detected at line 1)
```

الخطأ `SyntaxError` والسبب `unterminated string literal` (نص غير منتهي). فتحت علامة الاقتباس `"` في بداية النص لكنك نسيت إغلاقها في النهاية. بايثون ستظل تقرأ حتى نهاية الملف باحثة عن علامة الإغلاق.

الإصلاح: أغلق علامة الاقتباس.

```python
print("Student Name: Omar")
```
</details>

---

### 🧪 خطأ 3 — المسافة البادئة الخاطئة

```python
print("First Line")
    print("Second Line")
```

<details>
<summary>التحليل والإصلاح</summary>

المخرجات المتوقعة:

```text
  File "test.py", line 2
    print("Second Line")
IndentationError: unexpected indent
```

الخطأ `IndentationError` (خطأ في المسافات البادئة). بايثون لغة حساسة جدًا للمسافات في بداية السطر. السطر الثاني يبدأ بمسافات فارغة (Indentation) بدون أي سبب (مثل حلقة أو شرط)، وهذا يربك المترجم.

الإصلاح: احذف المسافات الزائدة من بداية السطر الثاني.

```python
print("First Line")
print("Second Line")
```
</details>

## تحدي المتعة 🎮 — الفن النصي (ASCII Art)

استخدم الدالة `print()` عدة مرات لرسم شكل بسيط لحاسوب أو كتاب باستخدام رموز لوحة المفاتيح العادية.

مثال للإلهام:

```text
  _______
 |       |
 | SCHOOL|
 |_______|
```

<details>
<summary>الحل</summary>

```python
print("  _______  ")
print(" |       | ")
print(" | SCHOOL| ")
print(" |_______| ")
```

جرّب رسم أشياء أخرى مثل سمكة، أو وجه مبتسم `:)`. هذا التمرين يدربك على الدقة في طباعة المسافات والأحرف!
</details>

## أخطاء شائعة عند المبتدئين

1. **نسيان الأقواس**: الدالة `print` تحتاج دائمًا إلى أقواس `()` حول ما تريد طباعته. `print "Hello"` خطأ في Python 3.
2. **استخدام الأقواس العربية**: الأقواس العربية `（ ）` لا تفهمها بايثون. يجب استخدام الأقواس الإنجليزية `( )`.
3. **علامات الاقتباس الذكية (المنحنية)**: إذا نسخت الكود من ملف Word أو WhatsApp، قد تتحول علامات الاقتباس إلى `" "` أو `' '`. هذه تكسر الكود. اكتبها دائمًا يدويًا من لوحة المفاتيح.
4. **الخلط بين الفاصلة والفاصلة المنقوطة**: بايثون لا تحتاج إلى فاصلة منقوطة `;` في نهاية السطور مثل لغات أخرى (C++ أو Java).
5. **نسيان حفظ الملف**: أحيانًا تكتب الكود وتشغله في الطرفية لكنه لا يتغير! تأكد دائمًا أنك حفظت الملف (`Ctrl+S`) قبل تشغيله.
